# Mangekyou Sharingan Images

This directory is intended to hold images of different Mangekyou Sharingan patterns from the Naruto series.

## Recommended Images to Add

1. **Itachi Uchiha's Mangekyou Sharingan** - Three-pronged pinwheel design
2. **Sasuke Uchiha's Mangekyou Sharingan** - Six-pointed star/atom design
3. **Obito Uchiha's Mangekyou Sharingan** - Triple-blade pinwheel design
4. **Madara Uchiha's Mangekyou Sharingan** - Windmill design with straight tomoe
5. **Shisui Uchiha's Mangekyou Sharingan** - Four-pointed pinwheel design
6. **Kakashi Hatake's Mangekyou Sharingan** - Same as Obito's left eye
7. **Sasuke's Eternal Mangekyou Sharingan** - Combined pattern of his and Itachi's designs

## Usage

When adding images to this directory, please:

1. Use PNG or SVG formats for best quality
2. Name files clearly (e.g., `itachi_mangekyou.png`)
3. Ensure you have rights to use the images
4. Keep file sizes reasonable (<500KB per image)
5. Include attribution if necessary

These images will enhance documentation and can potentially be displayed as part of the MCP's output in future versions.
